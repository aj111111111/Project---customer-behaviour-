📊 Customer Behavior Analysis & Business Intelligence
A comprehensive end-to-end data analytics project uncovering actionable retail insights through Python-based data cleaning, advanced SQL querying, and an interactive Power BI dashboard.

🚀 Project Overview
Understanding customer purchasing patterns is critical for modern retail optimization. This project takes raw retail data, cleans it using Python, extracts strategic business insights via 10 core SQL analytical questions, and visualizes key metrics through an interactive Power BI dashboard designed for stakeholder reporting.

🛠️ Tech Stack
Data Cleaning & Manipulation: Python, Pandas, NumPy

Data Analysis & Querying: SQL

Data Visualization & BI: Power BI

📌 Key Components & Workflow
1️⃣ Data Cleaning & Export (Python & Pandas)
Handling Missing Values: Addressed nulls and inconsistencies in the raw retail dataset.

Data Type Standardization: Converted dates, numerical values, and categorical variables into appropriate formats.

Exporting: Saved the finalized, analysis-ready dataset into a clean CSV file for seamless database ingestion.

2️⃣ Data Analysis using SQL (10 Business Q&As)
The core of this project relies on complex SQL queries to answer critical business questions and drive strategic decisions. Key business questions analyzed include:

What are the top-selling product categories by revenue and volume?

Who are the high-value repeat customers (RFM Analysis)?

How do sales trends fluctuate across different months/seasons?

3️⃣ Business Intelligence Dashboard (Power BI)
Designed an interactive, high-impact dashboard tailored for business stakeholders featuring:

High-Level KPIs: Total Revenue, Total Orders, Average Order Value (AOV), and Total Active Customers.

Geographic Distributions: Regional performance mapping to identify top-performing sales territories.

Segment-Level Insights: Deep dives into customer demographics, purchasing habits, and product preferences.
